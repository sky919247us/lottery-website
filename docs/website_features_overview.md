## 一、網站定位

**刮刮研究室** 是台灣彩券「刮刮樂」垂直分析平台，主打三件事：

1. 用**真實數據**告訴玩家「現在哪一款值得買」
2. 提供**理性購票工具**（殘值計算、PNL 紀錄）
3. 把刮刮樂彩券行整合成**實體店家服務生態**（地圖、現貨、商家認領）

資料來源：每日自動爬取台灣彩券官網 → 結構化儲存 → AI 解析玩法 → 多維度分析。

## 三、各頁功能詳解

### 1. 🏠 首頁（`/`）

#### 1.1 主標題 + 搜尋
- **標題**：「刮刮研究室 — 中獎率分析 × 殘值計算」
- **搜尋欄**：可輸入遊戲名稱或編號（如「一觸即發」、「5145」）
- **進階篩選**：售價區間（最低～最高）

#### 1.2 排序按鈕
- 🔥 熱門排行
- 💰 價格高低
- 🆕 最新上市
- 🎯 中獎率

#### 1.3 本週推薦輪播（最多 5 張卡）
依即時資料動態決定本週推薦：
| 標籤 | 推薦條件 |
|---|---|
| 🥇 本週最佳 CP | 中獎機率最高 |
| 🔥 熱銷款 | 大家都在買 |
| 🆕 新上架 | 剛上市，搶先體驗 |
| 💰 頭獎獵人 | 頭獎仍在，值得一搏 |
| 🎯 小資首選 | 小額投入，高機率中獎 |

#### 1.4 全部遊戲列表
- 顯示「共 N 款」
- 每款卡片：圖片、名稱、售價、銷售率、中獎率、最高獎金
- 「**NEW**」徽章（近 30 天上市）
- 點卡片進入詳情頁

---

### 2. 🎫 詳情頁（`/detail/:id`）

每款刮刮樂的完整數據檔案。

#### 2.1 基本資訊
- 票面圖片
- 名稱、編號、售價、發行張數
- 上市/停售日期、目前狀態（在售 / 已停售）
- 收藏 ⭐ 按鈕

#### 2.2 自動產生的特色徽章（依資料動態 1-3 個）
- 🔥 **高勝率** — 中獎率高於同價位平均
- 💎 **回本率高** — RTP > 設定門檻
- 👑 **頭獎仍在** — 頭獎尚未開出
- 🎯 **小額入門** — 售價 ≤ 100

#### 2.3 獎金結構表
完整列出每個獎項：獎項層級、獎金金額、中獎張數、中獎機率「幾張中一張」。

#### 2.4 玩法說明（AI 解析）
- 玩法機制標籤（match_any / match3 / bingo_line / multiplier 等）
- 複雜度評分（1-5 顆星）
- AI 生成 50 字內的玩法介紹（繁體中文）

#### 2.5 整本回本計算機
進階版殘值試算：輸入購買整本（100 張）後，預期回收金額分布。

#### 2.6 開箱影片
若該款有對應的 YouTube 開箱影片，自動嵌入。

#### 2.7 相似款式推薦
依玩法相似度 + 獎金結構相似度，推薦 Top 3 相似的歷史 / 在售款式。

- 點選款式進入詳情頁的殘值計算區

---

### 5. 💰 我的錢包（`/wallet`） — PNL Dashboard

個人化「刮樂盈虧紀錄」工具。

#### 5.1 摘要卡片
- 累積花費
- 累積中獎
- 累積盈虧（紅字虧損 / 綠字獲利）
- 整體 RTP

#### 5.2 紀錄輸入
- 款式名稱（可搜尋自動補完）
- 花費金額、中獎金額
- 加入紀錄按鈕

#### 5.3 圖表分析
- 累積盈虧趨勢圖
- 各款式投入分布
- 最賺/最賠款式排行

> **隱私**：紀錄僅存於使用者帳號名下，僅本人可見。

### 7. 🗺️ 中獎地圖（`/map`）

全台彩券行地理資訊整合 + 頭獎熱區可視化。

#### 7.1 上方統計
- 彩券行（全台筆數）

#### 7.2 區域快速篩選

#### 7.3 地圖層
- 一般彩券行（藍色標記）
- 運彩行（綠色標記）
- 雙營業（混合）

- 👑 PRO 商家（金色光暈 + 皇冠標記）

#### 7.4 標記點泡泡
點擊標記顯示：
- 店家名稱、地址
- 認證 ✅ 與 PRO ⭐ 徽章
- 來源（台灣彩券 / 台灣運彩）
- 📢 PRO 限定 — 店家公告
- 設施標籤（冷氣 / 廁所 / Wi-Fi / 電子支付 / 提供攻略 / 挑號服務 / 專業刮板…）
- 商家官方庫存（PRO 才顯示）
- 「庫存」「評分」「導航」「專屬頁面」按鈕

#### 7.5 列表模式（切換按鈕）
顯示「投注站列表 — 顯示 N / 共 N 間」清單版。

#### 7.6 全台中獎熱區（右側面板）
22 縣市分組，顯示各縣市本期頭獎開出最多的區域。

## 四、共通互動元素

### 4.1 LINE 登入按鈕
- 全站右上角（行動版折入漢堡選單）
- 點擊跳轉 LINE OAuth 授權頁
- 授權後自動建立帳號 + 回原頁

### 4.2 收藏 ⭐ 按鈕
- 出現在詳情頁與卡片上
- 需登入才能使用
- 加/移除收藏即時同步

### 4.3 評分系統
- 在地圖店家泡泡 / 店家頁面點「評分」
- 5 星評分 + 文字留言
- 顯示平均星等與評論數

### 4.4 即時搜尋
- 首頁 / 計算機 / 錢包輸入款式時
- 自動補完，輸入 1 字以上即觸發

### 4.5 響應式設計
- 桌機：頂部固定導覽
- 行動：底部 5 tab 固定導覽 + 右上漢堡選單
