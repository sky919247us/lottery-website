## 一、什麼是「店家認領」？

刮刮研究室地圖上的彩券行資料來自台灣彩券官網，但**僅限基本資訊**（店名、地址、營業狀態）。

「店家認領」就是讓**真正的店主**透過 LINE 認證後，把店面與帳號綁定，獲得一個專屬的商家後台，能：

- 維護店家資訊（公告、設施標籤、聯絡方式）
- 上傳店內環境照、中獎打卡照
- 管理現貨庫存（顧客在地圖上能看到「現貨充足」/ 「即將售完」）
- 享有專屬頁面、地圖優先排序、PRO 徽章等加值服務

> 認領是免費的；要解鎖完整功能需訂閱 PRO（年費 NT$1,680）。

## 二、認領流程（4 步驟）

### 步驟 1️⃣：LINE 登入
- 開瀏覽器訪問 https://i168.win
- 點右上角「**LINE 登入**」（綠色按鈕）
- 跳轉至 LINE OAuth 授權頁面 → 同意
- 自動回到首頁，右上角顯示你的 LINE 大頭貼

### 步驟 2️⃣：找到自己的店家
- 點頂部「**中獎地圖**」或行動版底部「地圖」
- 搜尋自己店家名稱（如「撿到錢投注站」）
- 或先選縣市 / 行政區縮小範圍
- 找到店家標記點 → 點開泡泡

### 步驟 3️⃣：點「認領這家店」
- 標記點泡泡內或店家清單卡片上會有「認領」按鈕
- 進入認領表單頁面 `/merchant/claim/:id`

#### 表單填寫項目
| 欄位 | 說明 | 必填 |
|---|---|---|
| 聯絡人姓名 | 老闆或負責人姓名 | ✅ |
| 聯絡電話 | 9 位數手機（不含 -）| ✅ |
| LINE ID 或顯示名 | 方便客服聯繫 | ✅ |
| 經銷證上傳 | 拍照或掃描台彩經銷證 | ✅ |
| 身分證上傳 | 證明你是該店實際營運人 | ✅ |

> ⚠️ 雙證件僅供審核，不會公開。審核通過後即從伺服器永久刪除原圖（僅保留審核紀錄）。

### 步驟 4️⃣：等待管理員審核
- 提交後狀態為「**審核中**」
- 通常**1 個工作日內**完成審核
- 審核通過會發送 **LINE 通知**：
  > 🎉 [店名] 認領申請已通過！您的商家帳號已建立，預設帳密為您的手機號碼。
- 審核未通過會收到原因說明，可修正後重送

## 三、商家帳號首次登入

### 帳號資訊
- **帳號**：你填的手機號碼（如 0912345678）
- **預設密碼**：與帳號同（**首次登入後請立即修改**）
- **登入網址**：https://i168.win/admin/login

### 登入後第一件事
- 右上角點頭像 → 「修改密碼」
- 輸入舊密碼 → 設定新密碼（建議 8 位以上含英數）

### 5.3 📦 現貨管理

#### 操作介面
- 「新增款式」按鈕 → 搜尋全部 143 款刮刮樂 → 加入庫存清單
- 每款設定庫存狀態：
  - 🟢 **充足**（顧客看到「充足」標籤）
  - 🟡 **少量**
  - 🔴 **缺貨**
- 一鍵刪除款式（不再販售時）

#### 顧客端如何受益
- 在地圖點開你店家會看到「**商家官方庫存**」清單
- 顧客查詢「附近有 5145 一觸即發」時，你會出現在結果中
- 比靠顧客自行詢問更精準，提升上門率

> ⚠️ 庫存狀態請每日更新，避免顧客白跑造成負評。

## 七、付費流程

### 步驟
1. 商家後台「店舖總覽」 → 點「**立即升級 PRO**」/「續約 PRO」按鈕
2. 跳轉至 SHOPLINE 結帳頁
   - 顯示商品名「刮刮研究室 PRO 專業版 (年費)」
   - 金額 NT$1,680
3. 選擇付款方式（信用卡 / Apple Pay）
4. 輸入卡號 / 持卡人姓名 / 有效期 / 安全碼
5. 勾選「我同意 SHOPLINE Payments 隱私權條款與服務細則」
6. 點「**支付 NT$1,680**」
7. 走 3DS 驗證（信用卡銀行會發**簡訊**到登記手機，輸入驗證碼）
8. 付款成功 → 系統自動升級 → 商家後台立刻變成「專業版」

### 退款
1. 聯繫客服或自行至 SHOPLINE 後台申請退款（依平台政策）
2. 銀行處理 1-3 工作日
3. 系統收到退款通知 → **自動降回基礎版**
4. 你的所有設定資料（公告、相簿、簡介）會保留，未來若再升級即立刻恢復顯示

## 九、常見問題

### Q1：我要怎麼知道我的店家已經在地圖上？
A：開地圖搜尋你店名即可。如果沒有 → 表示尚未被台彩官網收錄，請聯繫客服。

### Q2：認領後可以換手機號碼嗎？
A：手機號碼即帳號，無法直接更換。如需變更，請聯繫客服協助。

### Q3：一個 LINE 帳號可以認領幾家店？
A：**沒有上限**。同一 LINE 認領多家店時，後台會自動出現「管理店家」切換器，每家獨立 PRO / 庫存 / 設定。

### Q4：PRO 到期沒續約會怎樣？
A：自動降回基礎版。所有 PRO 限定功能（公告、專屬頁面、相簿、地圖加權）暫停顯示，但**所有設定資料會保留**，未來重新訂閱後立即恢復。

### Q5：可以分期付款嗎？
A：信用卡視發卡銀行而定，目前未開放官方分期。

### Q6：可以開發票嗎？
A：可以。SHOPLINE Payments 會自動發送電子發票到你填寫的 email；如需打統編，付款時填統編欄位。
